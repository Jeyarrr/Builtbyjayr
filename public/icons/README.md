# Technology brand marks

SVGs from [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0/icons), distributed with its MIT license in `LICENSE.txt`. Product names and marks belong to their respective owners and are used here to identify technologies, without implying endorsement.

Only the required marks are served locally. `scripts/download-brand-icons.mjs` refreshes this pinned set. The GitHub mark also identifies GitHub Pages; the .NET mark identifies ASP.NET. Git uses its own branching diamond logo, separate from GitHub.

Colored marks keep their colors in both themes. Monochrome GitHub, Express, and Vercel marks switch to white in dark mode for visibility.
Visual Studio and Visual Studio Code have separate marks.
